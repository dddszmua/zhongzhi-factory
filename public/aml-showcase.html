Why modular

为什么不直接生成最终系统？

因为业务系统不仅要“能跑”，还要知道为什么这样跑、哪里出了问题，以及如何只替换其中一个模块。

⌘

标准接口解耦

算法先封装成 MCP，智能体不需要理解不同代码结构，只需通过统一工具协议调用。

◇

能力可替换复用

风险识别算法升级时，只替换对应服务；报告生成和应用页面无需全部推倒重来。

✓

每一步可验收

算法结果、服务接口、智能体调用链都能独立测试，问题能够被定位到具体环节。

↗

复杂度逐层扩展

先用一个智能体编排多个服务完成闭环，再按业务规模扩展为更大的系统。

一次性生成黑盒路径
一句需求→直接生成系统→结果未知

中间决策不可见，局部错误难定位，想换一个算法时可能要重新生成整个系统。

众智工场显式流水线
算法→MCP→智能体→系统

每层都有清晰产物和控制点，用户可以确认、调整、替换、回退并重新验证。

Different by design

不是更大的代码助手，而是更清晰的应用生产方式

Codex、Claude Code 等产品擅长通用软件开发协作；众智工场聚焦业务算法资产的生成、服务化、编排和验证。

01把控制点内建到平台主流程，而不是依赖用户自己组织工程步骤。
02每一层都产出可保存、可复用、可独立测试的业务资产。
03让业务人员、算法团队与应用团队在同一条链路上协作。

通用代码协作产品

以代码库和开发任务为中心，适合编写、解释、修改和调试软件。它们同样可以配合人工审核与工程流程，但流程通常由开发团队自行设计。

众智工场

以业务目标和算法资源为中心，把“算法 → MCP → 智能体 → 应用”的控制点固化为可视流程，用户能参与每个关键决策并查看中间产物。

核心优势

可解释的编排过程、可复用的 MCP 服务池、可追踪的仿真验证，以及适合多个团队分工交付的模块化协作方式。

说明：这里比较的是产品定位与默认工作方式，并非断言其他工具“不可控”。众智工场的差异在于将业务应用生产的控制点直接产品化。

AML case study

案例：四个团队 + 四层平台流程，集成一套反洗钱系统

这不是一个模型包办全部环节，而是四个团队分别交付算法能力，再借助众智工场「算法 → 服务 → 智能体 → 系统」的标准流水线，一步步集成、验证并上线。

业务目标：识别可疑交易，验证模型可靠，输出合规报告

输入跨境交易与商户特征，输出风险等级、解释理由、处置建议和监管报告摘要。平台负责把分散的算法成果串成可运行的应用闭环。

跨境支付 · 综合风控
01

四个团队分工交付算法

每个团队专注一个专业能力，在平台上生成或上传算法模型，形成可登记、可测试的算法资产。

团队 01

交易风险识别

识别单笔和批量跨境交易中的异常模式，给出风险评分与关键信号。

交付物：可疑交易识别算法模型 风险识别与评估
团队 02

多方联合分析

面向多机构协作场景，在数据不出域前提下完成联合风险判断。

交付物：跨机构联合分析算法模型 跨机构联合分析
团队 04

模型安全指纹

验证风险模型在扰动下的可靠性，为识别结果提供置信依据。

交付物：模型安全评测算法模型 安全指纹评测
团队 03

金融风险报告

汇总风险数据、评测结论与处置建议，生成面向审核人员的报告。

交付物：合规报告生成算法模型 合规报告生成
02

按平台四层流程逐步集成

团队交付的是「能力模块」，平台负责封装、编排与接入。每一层都有明确产物，完成后才进入下一层。

第一层生成算法模型

四个团队分别在平台上完成算法生成或上传，登记为可复用的算法资产，并各自完成单元测试。

团队一 · 风险识别模型 团队二 · 联合分析模型 团队三 · 报告生成模型 团队四 · 安全评测模型
↓
第二层封装 MCP 微服务

平台将四个算法分别分析、封装并部署为标准化在线服务，智能体可通过统一接口远程调用。

风险识别服务 联合分析服务 安全评测服务 报告生成服务
↓
第三层组合元应用智能体

描述「跨境支付反洗钱综合研判」目标，选择上述服务并编排调用顺序，通过仿真验证整条处理链路。

识别异常 → 安全校验 → 生成报告
↓
第四层集成为应用系统

将已验证的智能体能力接入反洗钱业务界面，形成事中监测、风险查询与合规报告输出的应用闭环。

交易监测页 商户风险查询 监管报告导出

Capability boundary

哪些已经实现，哪些属于扩展方向

展示能力边界，不把演示数据当作生产实调用，也不把多 MCP 组合误写成通用多智能体系统。

当前平台已具备

✓通过自然语言想定生成算法源码并登记为算法资产
✓把算法分析、封装并部署为 MCP 微服务
✓一个元应用智能体编排多个 MCP 服务
✓仿真构建、验证、预发布与在线运行链路

系统级扩展愿景

→多个独立智能体在同一大型应用系统中协作
→跨元应用的消息路由、任务分配与全局调度
→从智能体能力自动生成完整多页面业务系统
→更多团队服务从演示实例升级为生产级在线实例
